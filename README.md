# Connect

A React component for seamless Web3 integration.

## Installation

You can install the package using npm:

```bash
npm install @npaymelabs/connect
```

or with yarn:

```bash
yarn add @npaymelabs/connect
```


## Development Requirements

- **Node.js**: v20.14.0
- **Yarn**: Latest version

Ensure you have the correct Node.js version installed. You can check your version with:

```bash
node -v
```

If you need to switch Node versions, consider using [nvm](https://github.com/nvm-sh/nvm) (Node Version Manager).
